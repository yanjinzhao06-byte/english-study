# 满分英语 · 河南专升本版（FullScore English）

> 从**高考英语 50 分**到**河南专升本公共英语满分(150 分)**的一站式学习应用。
> 纯本地静态应用：**无需联网、无需安装**，浏览器 / iPad 直接可用，数据保存在本机。

## 🚀 怎么用

### 1) 本机电脑直接打开
双击 **`启动本地服务器.bat`**（自动用 Python 或 Node 起一个本地服务并打开浏览器）。

> 也可以手动：在「英语」文件夹内执行 `python -m http.server 8000 --bind 0.0.0.0`，
> 然后浏览器访问 `http://127.0.0.1:8000`。

### 2) iPad / 手机（同一 Wi-Fi）
1. 电脑上双击启动脚本，记下脚本里打印的 `http://192.168.x.x:8000` 地址；
2. iPad 用 **Safari** 打开该地址；
3. 点 Safari 的「分享 → **添加到主屏幕**」→ 之后像 App 一样全屏打开；
4. 首次在线打开后，应用会缓存全部资源，**之后断网也能离线使用**。

### 3) 发布到公网（可选，最方便）
整个文件夹是纯静态站点，可直接拖到
[Netlify Drop](https://app.netlify.com/drop) 或 GitHub Pages / Vercel / 腾讯云 COS / 阿里云 OSS 静态托管，
得到一个公网网址，iPad 随时随地打开。

## 📌 使用建议（50 → 150 路线）

1. **第 1 天**：做「入学测评」→ 系统给出起始估分与所处阶段；
2. **P1(50-80)**：主页任务 → 每日 20 新词 + A 级语法课 + 首页打卡；
3. **P2(80-110)**：Tier2 词书 + B 级语法 + 阅读/完形专项；
4. **P3(110-135)**：Tier3 高频词 + C 级拔高 + 翻译/改错专项；
5. **P4(135-150)**：全真模考限时训练 + 写作范文背诵 + 错题清零冲刺满分；
6. 每周看「我的」页热力图与成绩趋势，别让🔥断掉。

## 🛠 技术说明

- 纯原生 HTML/CSS/JS（无任何依赖），`localStorage` 持久化；
- PWA：`manifest.webmanifest` + `sw.js`，支持添加到主屏幕与离线；
- 适配桌面 / iPad / 手机，iPad 横竖屏均可；
- 改配色 / 换字体 / 增题库：词书在 `js/data-vocab.js`，语法与测验在 `js/data-course.js`，专项题库在 `js/data-bank.js` / `js/data-bank2.js`，界面与逻辑在各 `js/ui-*.js`。
- 数据格式说明：词条为 `[单词, 词性, 释义, 难度]`；题目字段 `q` 题干、`o` 4 个选项、`a` 正确下标、`e` 解析。

## ⚠️ 说明

- 题库为**学习型模拟内容**，用于日常训练与自测；真题结构参考近年河南专升本公共英语试卷。
- 请自律学习，本应用不含任何形式的作弊或代考功能 😄
